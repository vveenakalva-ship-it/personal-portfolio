# 4. Implementation Details
## HTML5 & CSS3
Semantic HTML5, headings, paragraphs, lists, table, links, form and visual media are used. CSS selectors, box model, Flexbox, Grid, typography, gradients, glassmorphism, positioning and media queries are implemented.

## Bootstrap
The project is structured to support Bootstrap concepts including responsive layout, navigation, cards, forms, tables, buttons and components. The premium visual layer is implemented with custom CSS so the portfolio remains visually stable when opened locally.

## JavaScript
ES6-style variables, functions, arrow functions, conditions, DOM manipulation, event listeners, dynamic project filtering, theme switching, client-side validation and asynchronous Fetch API are implemented.
