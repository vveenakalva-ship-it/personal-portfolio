# Premium Personal Portfolio — Assignment 1

## Important
**Extract the ZIP before opening the project.** Do not run `index.html` from inside the ZIP preview.

### Run
1. Right-click the downloaded ZIP.
2. Select **Extract All**.
3. Open the extracted `Personal-Portfolio-Premium` folder.
4. Double-click `index.html`.

The main page contains embedded CSS and JavaScript so the premium design works reliably when opened locally. Separate `css/style.css` and `js/script.js` copies are also included for source-code inspection and GitHub submission.
